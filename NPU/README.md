## ⚠️ 引用性能数字前先看这个

本目录里有**四组不同前提**的数字，混着引用看起来会像打架：

| 来源 | 模型与前提 | 数字 |
|---|---|---|
| ① 技术文档 / 视频笔记 | YOLOv5s 640，**作者的板子** | 36 / 119 / 181–185 fps |
| ② §4 / ③ | YOLOv5s 640，**本板**，锁频 + 三核绑定 | 28.2 / 118.7 / 177.6 fps |
| ② §3.2–3.3 | ResNet18 224，**本板**，Python 侧含解释器开销 | 214 fps（单核）|
| 根 `../README.md` | MobileNetV1，**本板** | 482 / 1005 fps |

> 引用时**必须写明模型名与前提**。MobileNetV1 与 YOLOv5s **不是同一前提** ——
> 前者 224×224 亚毫秒级，数字高是因为模型小、测的多是宿主开销。
